# Economy Core

The NeoForge 1.21.1 companion mod for the Economy Pack. It adds:
- the Market Crate (sell market)
- the Supply Market (shop)
- the Frontier Gateway
- the Isles void dimension
- team-shared accounts, the balance HUD and the island-to-party link

Build with `./gradlew build` (bump `mod_version` in gradle.properties first). Configs live in
`config/economy_core/` (market.json, shop.json) and are generated by `economy-pack/tools/market_catalog.py`.
For full status and next steps, see `~/Modpacks/economy-pack/HANDOFF.md`.
